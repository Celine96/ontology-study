# M0. 멘탈모델 — 온톨로지란 무엇인가

> **이 모듈의 목표**: "트리플" 단 하나의 개념을 잡는다. 이것만 알면 나머지는 전부 응용이다.

## 한마디로

**온톨로지(ontology)** 는 "세상을 컴퓨터가 알아듣게 정리하는 방법"이에요.

::: tip 💡 쉽게 말하면
방 정리를 할 때 그냥 물건을 쌓아두면 나중에 못 찾죠. 그런데 "이건 장난감, 이건 책, 책은 책장에" 이렇게 **규칙을 정해서** 정리하면 누구나 찾을 수 있어요.
**온톨로지** = 컴퓨터가 그렇게 찾고·연결할 수 있도록 세상을 규칙 있게 정리해 둔 것.
:::

## 왜 배우나

폴더·태그·엑셀은 "내가 분류한 것"만 담아요. 온톨로지는 한 걸음 더 나아가 **"누가 누구랑 어떤 사이인지"**까지 담아요.

그래서 사람이 일일이 안 적어도 컴퓨터가 스스로 **추론**(M3에서 자세히)해서 추천·요약·자동 리포트를 만들 수 있어요.

## 핵심 개념 — 딱 4개 + 1개

온톨로지는 세상을 이 4가지로 봐요.

- **개체** (Instance / Entity) — 진짜로 있는 '그것 하나'
  - 예: 우리 반 민수, 서초문화예술공원
- **클래스** (Class / Type) — 그것들의 '종류·무리'
  - 예: 학생, 행사장
- **속성** (Property / Attribute) — 그것이 가진 '값'(숫자·날짜·이름)
  - 예: 키 = 140cm, 개최일 = 10월 17일
- **관계** (Relation) — 그것과 '다른 것'을 잇는 선
  - 예: 민수 →(짝꿍이다)→ 영희

::: tip 💡 클래스 vs 개체, 헷갈리면 이렇게
**클래스 = 붕어빵 틀**, **개체(인스턴스) = 그 틀로 구운 붕어빵 하나**. 틀은 '종류'고, 붕어빵은 '진짜 하나하나'예요. "학생"은 클래스, "민수"는 인스턴스.
:::

### 가장 중요한 것 = 트리플(Triple)

**트리플** 은 모든 지식을 `주어 - 서술어 - 목적어` **세 칸**으로 쪼갠 거예요. 사실 우리가 매일 쓰는 말이 이미 트리플이에요.

> 아래에 나오는 `is a`(이즈 어)는 "~는 ~의 한 종류다"라는 뜻의 약속된 말이에요. 예: "고래 is a 동물" = "고래는 동물의 한 종류다".

```
( 민수 )         →  좋아한다  →  ( 피자 )
( 서초AI페스타 )  →  is a     →  ( 지역축제 )        … 종류 말하기
( 참여기업A )     →  운영한다  →  ( 부스#12 )          … 관계
( 서초AI페스타 )  →  개최일    →  ( "2026-10-17" )    … 속성(값)
```

이런 트리플 수백 개가 모이면 → 그게 바로 **지식그래프**(M4에서 배워요)예요. 트리플 하나만 머리에 넣으면 온톨로지의 절반은 끝난 거예요.

## 실습 ✏️

서초 AI 페스타에 대해 **트리플 7개**를 손으로 적어요. 그중에 꼭 —

- 1개는 **관계** (화살표가 다른 것으로 가는 것)
- 1개는 **속성** (값이 날짜·숫자·이름인 것)
- 1개는 **is a** (종류 말하기)

> 어려우면 "페스타에 대해 아는 것 3개"를 그냥 말로 적은 뒤, 세 칸으로 쪼개는 것부터 시작해도 돼요.
