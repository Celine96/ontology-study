# M0. 멘탈모델 — 온톨로지란 무엇인가

> **이 모듈의 목표**: "트리플" 단 하나의 개념을 잡는다. 이것만 체화하면 나머지는 전부 응용이다.

## 왜 배우나

폴더·태그·엑셀은 "내가 분류한 것"만 담는다. 온톨로지는 **"개체들이 서로 어떤 관계인지"**를 담아서, 사람이 적지 않은 사실까지 컴퓨터가 **추론**하게 만든다. 큐레이션·추천·자동 리포트가 전부 여기서 나온다.

## 핵심 개념 — 딱 4개 + 1개

온톨로지는 세상을 이 4가지로 본다:

| 요소 | 영어 | 뜻 | 예 |
|---|---|---|---|
| 개체 | Instance / Entity | 세상에 실제 존재하는 '그것 하나' | 서초문화예술공원, 부스#12 |
| 클래스 | Class / Type | 개체들의 '종류' | 행사장, 체험부스 |
| 속성 | Property / Attribute | 개체가 가진 값 | 개최일=10/17, 부스수=50+ |
| 관계 | Relation | 개체와 개체를 잇는 선 | 참여기업A **가-운영한다→** 부스#12 |

**가장 중요한 단위 = 트리플(Triple)**: 모든 지식을 `주어 - 서술어 - 목적어`로 쪼갠다.

```
(서초AI페스타)   - (is a) -     (지역축제)          ← 클래스 소속
(참여기업A)      - (운영한다) -   (부스#12)           ← 관계
(서초AI페스타)   - (개최일) -    ("2026-10-17")      ← 속성
```

지식그래프 전체는 결국 **이 트리플의 거대한 묶음**이다. 이거 하나만 체화하면 나머지는 다 응용이다.

::: tip 우리가 쓰는 문장이 이미 트리플
"서초 AI 페스타는 10월 17일에 열린다" → (서초 AI 페스타) - (개최일) - (2026-10-17). 평소 문장을 세 칸으로 쪼개는 연습이 곧 온톨로지 설계다.
:::

## 레포에서 볼 곳

## 실습 ✏️

서초 AI 페스타에 대해 **트리플 7개**를 손으로 적는다. 최소 1개는 관계(개체→개체), 1개는 속성(개체→값), 1개는 클래스 소속(is a).

> 부담되면 "페스타에 대해 아는 사실 3개"를 평범한 문장으로 적은 뒤, 세 칸으로 쪼개보는 것부터 시작해도 된다.
