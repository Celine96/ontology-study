# M5. 실전 — 내 온톨로지 만들기 (onto-osint fork)

> **목표**: 앞 모듈에서 손으로 적은 것들을 **실제 돌아가는 시스템**으로 만든다. "딱 2파일만 바꾸면 도메인이 바뀐다"는 설계를 이용한다.

## 순서

1. 레포 fork/clone → `onto-osint-seocho-aifesta`
2. `config/osint-config.json` 수정: 지역(서초구), 출처(서초구청·페스타 공식·AI행사 매체), 클래스 시드(M1 결과), 타겟존(전시존/피지컬AI존…)
3. `CLAUDE.md` 수정: 추론 규칙(M3 결과) + 도메인 판단 기준
4. 하루치 파이프라인 실행 → 첫 리포트 1장 생성
5. 결과를 보고 규칙·클래스 다듬기 (반복)

## 부동산으로 확장 (장기)

같은 엔진을 한 번 더 fork:

- `Event→Venue→Dong` ⟹ `매물→단지→생활권`
- 추론: `역세권_가산점`, `동일생활권_연계`, `가격조정_임박(D-3)`
- → 온토에어 부동산 온톨로지 = 태영님이 기대한 "수연님이 어느정도 할 수 있는 상태"
