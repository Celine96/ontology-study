# M5. 실전 — 서초 AI 페스타 온톨로지 (onto-osint fork)

> **이번 프로젝트의 결승선.** 앞에서 손으로 적은 것들을 **진짜 돌아가는 시스템**으로 만든다.

## 한마디로

이미 잘 만들어진 레포를 **복사해서(fork)**, **딱 2개 파일만** 서초 페스타용으로 바꾼다.

::: tip 💡 쉽게 말하면 (레시피 바꾸기)
맛있는 김밥 레시피가 있어요. 재료만 바꾸면 참치김밥, 치즈김밥이 되죠?
onto-osint도 똑같아요. 이미 "유성구 어린이 행사" 레시피가 완성돼 있는데, **재료(설정 2개)** 만 "서초 AI 페스타"로 바꾸면 우리 버전이 돼요. 요리법(파이프라인) 전체는 그대로 물려받아요.
- **fork(포크)** = 남의 레포를 내 것으로 통째로 복사해 오는 것
:::

## 순서

1. 레포 fork/clone → `onto-osint-seocho-aifesta` (복사해 오기)
2. `config/osint-config.json` 수정: 지역(서초구), 출처(서초구청·페스타 공식·AI행사 매체), 클래스 시드(M1 결과), 타겟존(전시존/피지컬AI존…)
   > **config(컨피그)** = "설정 파일". 어디를 크롤링하고 어떤 종류를 다룰지 적는 곳.
3. `CLAUDE.md` 수정: 추론 규칙(M3 결과) + 판단 기준 적기
4. 하루치 파이프라인 실행 → 첫 리포트 1장 생성
   > **파이프라인(pipeline)** = 수집 → 추출 → 추론 → 리포트로 이어지는 **공장 컨베이어벨트** 같은 자동 흐름.
5. 결과를 보고 규칙·클래스를 다듬기 (반복) → 며칠 돌려서 안정화

## 결승선 — 이 프로젝트의 완성 모습

- 서초 AI 페스타 부스·강연·기관을 담은 **온톨로지**(클래스 + 관계 + 추론 규칙)
- 그 위에서 매일 도는 **일일 큐레이션 리포트** (추천 부스 / 신규 / 마감 임박 / 존별 동선)
- 지식그래프 **그림 1장**(M4) — 페스타 전시·홍보에 바로 쓸 수 있는 결과물
