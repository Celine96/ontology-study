# M5. 실전 — 서초 AI 페스타 온톨로지 (onto-osint fork)

> **이번 프로젝트의 결승선.** 앞 모듈에서 손으로 적은 것들을 **실제 돌아가는 시스템**으로 만든다. "딱 2파일만 바꾸면 도메인이 바뀐다"는 설계를 이용한다.

## 순서

1. 레포 fork/clone → `onto-osint-seocho-aifesta`
2. `config/osint-config.json` 수정: 지역(서초구), 출처(서초구청·페스타 공식·AI행사 매체), 클래스 시드(M1 결과), 타겟존(전시존/피지컬AI존…)
3. `CLAUDE.md` 수정: 추론 규칙(M3 결과) + 도메인 판단 기준
4. 하루치 파이프라인 실행 → 첫 리포트 1장 생성
5. 결과를 보고 규칙·클래스 다듬기 (반복) → 며칠치를 돌려 안정화

## 결승선 — 이 프로젝트의 완성 모습

- 서초 AI 페스타 부스·강연·기관을 담은 **온톨로지(클래스+관계+추론 규칙)**
- 그 위에서 매일 도는 **일일 큐레이션 리포트** (추천 부스 / 신규 / 마감 임박 / 존별 동선)
- 지식그래프 **시각화 1장** (M4) — 페스타 전시·기획단 홍보에 바로 쓸 수 있는 산출물
