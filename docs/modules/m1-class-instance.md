# M1. 클래스 & 인스턴스 — 세상을 '종류'로 나누기

> **목표**: 클래스 계층(taxonomy)을 이해하고, 내 도메인의 클래스 트리를 그린다.

## 핵심 개념

- **클래스 = 종류(붕어빵 틀)**, **인스턴스 = 실제 개체(구운 붕어빵 하나)**.
- 클래스는 **계층(taxonomy)**을 이룬다: `행사장 ⊃ 실내행사장 ⊃ 전시홀`. 이 위계 관계가 **is-a / 상위클래스(subClassOf)**.
- 위계의 힘: "전시홀은 실내행사장이다"라고만 적어두면, "실내행사장의 성질"을 전시홀이 **자동 상속**한다. (← 추론의 씨앗)

## onto-osint 대응

- `ontology/schema.json` = **클래스/속성 정의** (틀)
- `ontology/instances.json` = **실제 장소·기관·동 누적 DB** (붕어빵들)
- 핵심 클래스 위계: `Event → Venue → Dong`, 그리고 `Organization, Activity, AgeGroup`

## 서초 AI 페스타로 옮기면

```
클래스 트리(초안)
- 행사(Event)
   └ 부스세션 / 강연 / 체험프로그램 / 공모전
- 공간(Venue)
   └ 전시존 / 피지컬AI존 / 무대
- 주체(Organization)
   └ 참여기업 / 기관 / 공동기획단
- 기술분야(AITopic)
   └ 생성형AI / 로봇(피지컬AI) / 음성 / 비전 ...
- 대상세대(AgeGroup)
   └ 아동 / 여성 / 장애인 / 어르신 / 가족전연령
```

## 실습 ✏️

위 클래스 트리를 **수연님 버전으로 다시 그린다.** 부스 3개를 골라 각각 어느 클래스의 인스턴스인지, 속성 2개씩(주최, 대상세대 등) 붙인다.
