# M3. 추론 — 온톨로지가 '똑똑한' 이유

> **목표**: 명시적 사실과 추론된 사실을 구분하고, if-then 추론 규칙을 직접 쓴다. (이게 이 레포의 알맹이다.)

## 핵심 개념 — 적지 않은 사실을 컴퓨터가 만들어낸다

- **명시적 사실**: 내가 적은 트리플.
- **추론된 사실**: 규칙에 따라 컴퓨터가 **새로** 도출한 트리플.
- 추론의 종류:
  - **상속**: "전시홀 ⊂ 실내행사장" + "실내행사장은 우천대체 가능" → "전시홀은 우천대체 가능" (자동)
  - **규칙(if-then)**: "같은 동 + 같은 날 두 이벤트면 → 콤보로 묶어라"
  - **전이/대칭**: A-인접-B, B-인접-C ⟹ A-인접-C (전이성)

## onto-osint 대응

`CLAUDE.md` + 리포트의 "추론 결과"에서:

| 규칙 | 의미 | 신뢰도 |
|---|---|---|
| `same_dong_combo` | 같은 동·같은 날 → 동선 콤보로 번들 | 0.92 |
| `same_date_cross_dong` | 같은 날 다른 동 → 연계 추천 | 0.80 |
| `operator_kid_friendliness` | 도서관·과학관 운영 → 어린이 친화 가산점 | — |
| `indoor_rainy_fallback` | 우천 시 같은 동 실내 대체 후보 | — |

::: warning 관찰 포인트 — 신뢰도 점수
추론마다 **신뢰도 점수(0~1)**가 붙는다. 온톨로지가 100% 확신이 아니라 "얼마나 그럴듯한가"를 다룬다는 것. 추천·큐레이션의 **정렬 기준**이 여기서 나온다.
:::

## 서초 AI 페스타로 옮기면 (직접 번역해보기)

- `operator_kid_friendliness` → `physical_ai_zone_bonus` : 피지컬AI존 부스 가산점
- `same_dong_combo` → `same_zone_combo` : 같은 존 부스 동선 추천
- `indoor_rainy_fallback` → `crowded_alt_booth` : 인기 부스 대기 길면 같은 주제 대체 부스 추천
- (홍보) `promo_priority` : 화제성 높은(피지컬AI·공모전 등) 부스 → 기획단 홍보 우선순위↑

## 실습 ✏️

서초용 추론 규칙 **2개**를 `if (조건) then (도출 트리플) [신뢰도]` 형식으로 직접 쓴다. 그중 1개는 기획단 홍보 업무와 연결되게.
