# 부록 — 표준·도구 & 진도표

## 더 깊이 — 표준과 도구 (지금 당장은 몰라도 됨)

onto-osint는 JSON 기반의 실용 온톨로지다. 학계·산업 표준으로 더 깊이 가려면:

| 키워드 | 한 줄 정의 | 언제 필요? |
|---|---|---|
| **RDF** | 트리플의 표준 표기법 | 데이터 교환·공개 시 |
| **RDFS / OWL** | 클래스·관계·추론을 형식적으로 정의하는 언어 | 엄밀한 추론·검증 필요 시 |
| **SPARQL** | 지식그래프용 질의 언어(SQL의 그래프판) | 그래프에서 복잡한 검색 시 |
| **Protégé** | 온톨로지 설계 GUI 툴 | OWL 본격 설계 시 |
| **Neo4j** | 그래프 DB | 대규모 KG 저장·질의 시 |

::: tip 학습 순서 추천
M0~M5(실용)로 감각을 먼저 만들고 → 필요할 때 RDF/OWL로 "형식화" → SPARQL로 "질의". **표준부터 들어가면 대부분 중도 포기한다.**
:::
